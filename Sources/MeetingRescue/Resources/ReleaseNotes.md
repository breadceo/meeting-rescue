# Meeting Rescue v0.1.25


- 공증 없는 DMG 배포를 명시적으로 선택할 수 있게 하고, 배포 안내와 검증 상태를 릴리즈 노트에 표시합니다.
- 긴 회의의 새 transcript 구간을 다시 잘라 일부 발화가 분석에서 빠지던 문제를 수정했습니다.
- Codex의 Economy, Balanced, Frontier preset이 Luna를 사용하고 추론 강도로 구분되도록 변경했습니다.
- OpenAI API 응답 모델명, 실제 입출력·합계·캐시·추론 토큰과 response ID를 분석 기록에 저장하고 추정값과 구분합니다.
- Custom Command의 기존 JSON 출력 호환성을 유지하면서 실제 사용량 메타데이터 전달을 지원합니다.

배포 안내: 이 버전은 Apple 공증을 받지 않았습니다 (unnotarized). macOS에서 경고가 표시되거나 실행이 제한될 수 있습니다.
